# Fake News Detection

This project focuses on detecting fake news using machine learning and natural language processing techniques, with the goal of identifying patterns in textual data and building a reliable classification system.

## Objective
Develop a model capable of automatically classifying news articles as true or fake, supporting the identification of misleading or unreliable information.

## Data
The project is based on two datasets containing real and fake news articles in English, including textual content and additional descriptive information such as title, subject and publication date.

Due to file size limitations, the datasets are not included in this repository.

## Tools
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib / Seaborn
- NLP techniques (text preprocessing, vectorization, topic modeling)

## Results
- Identification of recurring linguistic patterns in fake news, particularly in titles
- Detection of differences in structure and style between true and fake news
- Comparison of multiple classification models
- Selection of Logistic Regression as the most suitable model based on performance and interpretability
- Development of a reliable system for automatic news classification
